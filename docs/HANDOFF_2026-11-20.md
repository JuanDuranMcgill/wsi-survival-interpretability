## Literature review: decisions and papers considered (2026-11-20)
Full notes, with DOIs and how each reference was checked: `docs/lit/sample_size_theory.md`,
`docs/lit/wsi_cohorts.md`, `docs/lit/explanation_sample_size.md`. Numbers marked "own
calculation" there are ours (simulation or re-implementation), not published results.

Decisions taken from the review:
1. **The paper's "under ~200 events is too small" claim stands, with a nuance.** 139-163
   events give the overall C-index to about +/-0.05 (Collins 2016: >= 100, preferably >= 200
   events), but not anything that splits the events: subgroup or high-error comparisons,
   interactions, per-feature tests. Those need about 4x more events (Brookes 2001/2004;
   16x for half-size effects, Gelman). Still to do in the paper: cite Harrell, Peduzzi,
   Riley and Collins where the claim is made.
2. **Event target for the extension: roughly 600-1,000+ events.** Riley 2019/2020 needs about
   510 (C 0.70) to 880 (C 0.65) events for a ~25-parameter Cox model; a C-index difference of
   0.10 between equal halves needs about 310 events, 0.05 about 1,250; a ratio of hazard
   ratios of 2 about 260, of 1.5 about 760. Flexible models need more than these regression
   minimums (van der Ploeg 2014; Infante 2023).
3. **No single TCGA cancer type is large enough**, so the extension pools types (manifest:
   22 types with >= 50 events, 2,974 events).
4. **Pooling safeguards, all from the review:** C-index on within-type pairs only (stratified,
   as Wulczyn 2020); Cox stratified by cancer type; folds split by institution (Howard 2021;
   site-preserved CV cut PORPOISE from 0.606 to 0.576, Howard 2023); no cancer type as a model
   input (PROGPATH does this); tissue importance read within type, since a pooled C-index is
   at or above every per-type value (Song 2025) and tissue importance can encode cancer type.
5. **Approaches:** A, TCGA pan-cancer plus an events curve and a planted-signal power curve
   (chosen); B, a large external single-cancer cohort (chosen, applications to start); C, a
   stronger model on the same two cancers (dropped: the event count is the binding limit).
6. **The gap the extension fills:** no study measures how MIL explanation reliability changes
   with cohort size. Hence the events curve, reporting each test's minimum detectable effect
   (a failed test with a large one is inconclusive, not a refutation), a planted-signal power
   curve, and spread across training seeds (MIL run-to-run variance is large, Mammadov 2025).
7. **External cohorts considered (for B):**
   - Plausibly several hundred events in one cancer, all by application: PLCO via NCI CDAS
     (breast 1,012, colorectal 749, prostate 1,095, lung 492, bladder 284 patients); DACHS
     colorectal (2,271, via the study PIs / Kather lab); MCO colorectal (~1,500, fees);
     TransSCOT colorectal (3,182, on request); QUASAR 2 / VICTOR (trial groups); Swedish
     breast cohorts (351/389/226 RFS events, not shareable).
   - Public but too small: HANCOCK head and neck (701 WSIs), SurGen colorectal (161 deaths,
     5-year label only), LEOPARD prostate (508), CPTAC (< 160 deaths per type), NLST lung
     (~450 patients).
8. **Models considered:** the Kather lab DACHS colorectal model (public MIT weights; TCGA-CRC
   was its external test, OS C 0.64, DSS 0.69); PROGPATH (pan-cancer, public weights, but
   TCGA is probably in its training set and cancer type is an input); CHIEF (gated weights,
   no survival head); MCAT (needs genomics); TITAN, MUSK, Prov-GigaPath (encoders, not
   survival models); PORPOISE, SurvPath, Patho-Bench, STAMP (code and splits, no survival
   checkpoints).
