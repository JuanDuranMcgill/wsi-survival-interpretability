## 4. What the literature review taught us (2026-11-20; full notes in `docs/lit/`)
1. 139-163 events give the overall C-index to about +/-0.05 (Collins 2016), but anything
   that splits the events needs about 4x more (Brookes; 16x for half-size effects, Gelman).
2. Target for the extension: about 600-1,000+ events (Riley: 510-880 for a ~25-parameter
   Cox; C difference 0.10 between halves about 310, 0.05 about 1,250).
3. No single TCGA type is big enough; pool types (manifest: 22 types, 2,974 PFI events).
4. Pooling safeguards: within-type C-index (Wulczyn 2020), Cox stratified by type,
   institution-split folds (Howard 2021, 2023), no cancer type as a model input (PROGPATH
   does), read tissue importance within type (a pooled C is at or above every per-type
   value, Song 2025).
5. Gap we fill: nobody measures how MIL explanation reliability grows with cohort size;
   report each test's minimum detectable effect; planted-signal power curve; seed spread.
6. External cohorts: PLCO (breast 1,012, CRC 749, prostate 1,095, lung 492, bladder 284
   patients; CDAS application), DACHS (2,271), MCO (~1,500, fees), TransSCOT (3,182),
   Swedish breast (not shareable). Too small: HANCOCK, SurGen, LEOPARD, CPTAC (< 160
   deaths per type), NLST.
7. Models: Kather DACHS CRC model (MIT weights; TCGA-CRC external, OS C 0.64, DSS 0.69);
   PROGPATH (TCGA likely in-sample; cancer type is an input); CHIEF, MCAT, TITAN, MUSK.
8. Do not cite (unverified): the "m/10 or m/20" Harrell-Lee-Mark sentence, a "5-9 EPV"
   Vittinghoff figure, Riley 2025 Lancet DH on deep-model parameters, Campanella 2019 on
   training size, the MED3pa supplement.
